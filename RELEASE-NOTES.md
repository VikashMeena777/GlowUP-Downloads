# Glow Up 1.3.3 — stable release

## What changed
- Account settings now have clearly spaced sections and a visible DELETE confirmation field with safe cancellation and retry states.
- Fixed browser account-deletion requests, while retaining verified-session and exact confirmation requirements.
- Improved website and Help & support navigation in the web journal, with a consistent paper-and-ink layout.
- Support requests prevent duplicate submissions and preserve drafts when saving fails.
- Improved settings scrolling, keyboard focus, disabled controls and destructive-action styling.
- Updates the existing glowup.vikashbuilds.in app in place using the same release signature. Keep your installed app; Android asks for confirmation before updating.

## Install or update
1. Download `glowup-1.3.3.apk` from this release.
2. Open it and confirm the Android install or update prompt. Do not uninstall the current `glowup.vikashbuilds.in` app first.
3. Open glowup; your existing signed-in session and journal are retained when updating in place.

## Legacy app
- The old `com.glowup.app` package is separate. Sign in to this app to restore cloud data; export device-only preview entries before removing a legacy build.
