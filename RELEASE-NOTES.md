# Glow Up 1.3.0 — stable release

## What changed
- Google sign-in is now available on Android and the web, alongside email signup and password recovery.
- Email signup keeps the display name you chose instead of replacing it with the email prefix.
- The aura leaderboard and community highlights show each account once, including your signed-in account.
- A separate public website now includes a homepage, features, Android downloads, help, privacy, terms and account-deletion guidance.
- Improved account recovery, safe OAuth callbacks and signed-in support request submission.
- Updates the existing glowup.vikashbuilds.in app in place using the same release signature. Keep your installed app; Android asks for confirmation before updating.

## Install or update
1. Download `glowup-1.3.0.apk` from this release.
2. Open it and confirm the Android install or update prompt. Do not uninstall the current `glowup.vikashbuilds.in` app first.
3. Open glowup; your existing signed-in session and journal are retained when updating in place.

## Legacy app
- The old `com.glowup.app` package is separate. Sign in to this app to restore cloud data; export device-only preview entries before removing a legacy build.
